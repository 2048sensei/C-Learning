# C 语言学习 · 便携版使用说明

## 一键开始

先完整解压 ZIP，双击 `开始学习.exe`。顶层只有：

    C-Learning/
      开始学习.exe
      学习资源/

启动器使用 Windows 自带 .NET Framework，打开默认浏览器后立即退出，不安装软件、不需要 Node/Python、不运行后台服务、不联网下载。若系统没有配置 HTML 默认打开程序，或启动器被安全软件拦截，可在“学习资源”里直接打开 index.html。本地编译的启动器未做数字签名，不建议为运行它关闭系统安全保护。

## 学习记录怎样保存

章节完成、最近学习章节、测验与错题、12 项实践记录会在操作时自动保存到当前浏览器的本地存储。侧边栏显示保存状态；写入失败会明确提示，不会伪装成已保存。页面中没有笔记功能，也不会主动删除旧版本留在浏览器里的笔记。

进度不是写在启动器或资源文件夹里。请使用同一浏览器的普通窗口，并保持文件夹路径不变。浏览器对 file:// 的存储策略存在差异，不能承诺不同浏览器之间共享。勿用无痕窗口长期学习；清除浏览器数据、移动目录、换浏览器、换电脑或切换到本地服务器地址都可能导致旧记录不可见。

本版本在第一次保存时读取并迁移兼容的旧版学习记录，不清除旧键；同时尽力保留上一份有效的本地副本。副本和主记录仍属于浏览器数据，不能代替独立备份。

## 备份与恢复

首页展开“学习数据”，点击“导出进度备份”，将 JSON 文件保存到自己选定的磁盘目录；默认可能进入浏览器下载目录，请确认文件确实落盘。备份包含完成进度、最近学习、测验和错题、实践记录，不含笔记及主题偏好。

导入时先选择 JSON 文件，查看记录数量，再确认恢复：

- 合并：保留两边已完成章节和实践；同一道测验使用时间较新的结果，最近学习优先保留本机。
- 覆盖：完全使用备份中的学习记录，需二次确认；建议先备份当前记录。
- 非本应用备份、错误格式、不支持的版本或超过 1 MB 的文件会被拒绝，不改动当前记录。

升级前先在旧版本导出；在新版本导入后确认进度，再决定是否移除旧程序。移动便携目录前也应执行一次备份。

## 开发与验收

源码目录运行 `npm run package`，会验证 25 个页面、运行本地状态单元测试、生成静态页面和启动器，随后输出便携目录和 ZIP。旧发布目录不会被覆盖或删除。

`PLAYWRIGHT_MODULE` 指定已有 Playwright 后，可运行 `npm run test:e2e`。
`npm run test:package` 验证最新发布 ZIP：解压到独立含空格/中文的目录、检查清单哈希和两项顶层结构、执行启动器 --check，并对解压后的真实页面运行浏览器验收。测试使用独立浏览器配置，不读取或修改日常学习记录。

“学习资源/release-info.json”包含生成时间、版本和文件 SHA-256，可用于核对文件是否完整，不是数字签名。
